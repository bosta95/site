# VisionZone

Site statique prêt à être publié avec GitHub Pages.

## Publication gratuite

1. Crée un dépôt GitHub public.
2. Envoie le contenu du dossier `public` à la racine du dépôt.
3. Dans GitHub, ouvre **Settings → Pages**, puis choisis la branche `main` et le dossier `/ (root)`.
4. GitHub fournira une adresse en `github.io` et un certificat HTTPS.

## Contact et paiement

Les boutons de contact et des formules ouvrent WhatsApp. Le lien de paiement est envoyé manuellement après échange. Aucune clé, donnée bancaire ou fichier `.env` ne doit être ajouté au dépôt.

## Référencement

Quand l'adresse GitHub Pages est connue, ajoute un sitemap avec cette adresse exacte et déclare-le dans Google Search Console.
